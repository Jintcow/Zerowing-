# Нулевое крыло — установка на iPhone

1. Загрузите содержимое этого ZIP в корень репозитория GitHub (не сам ZIP).
2. GitHub → Settings → Pages → Deploy from a branch → main / (root) → Save.
3. Откройте опубликованную HTTPS-ссылку в Safari. Дождитесь загрузки игры и ещё 30–60 секунд, пока Safari сохраняет файлы (~18 МБ). Для надёжности обновите страницу при наличии интернета.
4. Safari → Поделиться → На экран «Домой» → Добавить.
5. Проверьте: включите авиарежим, откройте игру с домашнего экрана.

Важно: установка из ZIP или через http://localhost:8000 не даёт переносимой офлайн-установки PWA. Системный шрифт будет использован, если Google Fonts недоступен. iOS может очистить данные сайта при нехватке места; делайте резервные копии сохранений.

При выпуске новой версии замените файлы в репозитории и измените версию CACHE в service-worker.js (или пересоберите архив). Для установки обновления откройте игру онлайн и перезапустите её.
